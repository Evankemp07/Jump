# **Overview**

As a software engineer, I am always looking for opportunities to expand my skills in game development and real-time physics-based mechanics. This project allowed me to explore **Python game development using Pygame**, focusing on **platform movement, collision detection, and interactive gameplay elements**.

The game I developed is a **2D jumping game** where the player **jumps from platform to platform**, avoiding falling off the screen. Some platforms **move horizontally**, while others may **fade away after being stepped on**. **Power-ups** are placed randomly on some platforms providing boosts that allow the player to jump higher. The game ends if the player falls off the platforms.

The purpose of writing this software was to strengthen my understanding of **game physics, object-oriented programming (OOP), and collision handling**. It also helped me refine my **debugging skills** by addressing issues such as power-up movement, disappearing platforms, and game-over conditions.
